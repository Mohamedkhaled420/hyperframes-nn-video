        "# Hyperframes batch renderer (GPU) — Google Drive edition\n",
        "\n",
        "Renders **one video per row** of a `jobs.csv` file, using the Colab GPU (NVENC encoding + hardware Chrome via EGL), and saves each video back into its own Drive folder.\n",
        "\n",
        "**Before you start:** `Runtime → Change runtime type → T4 GPU`.\n",
        "\n",
        "## Drive layout\n",
        "\n",
        "```\n",
        "MyDrive/hyperframes_projects/        <- DRIVE_ROOT (configurable)\n",
        "├── jobs.csv                         <- one row per video\n",
        "├── dayflow_launch/                  <- one folder per video\n",
        "│   ├── anything.html                <- your composition (any name)\n",
        "│   ├── assets/ (logo.png, bg.jpg…)  <- everything the HTML references\n",
        "│   └── dayflow_launch.mp4           <- output is written here\n",
        "└── another_video/\n",
        "    ├── promo.html\n",
        "    └── assets/\n",
        "```\n",
        "\n",
        "## `jobs.csv` columns\n",
        "\n",
        "Only **`folder`** is required. Blank cells use the defaults from the config cell.\n",
        "\n",
        "| column | meaning | example |\n",
        "|---|---|---|\n",
        "| `folder` | Sub-folder of DRIVE_ROOT holding the HTML + assets | `dayflow_launch` |\n",
        "| `html` | HTML file name. Blank = the single `.html` in the folder | `promo.html` |\n",
        "| `output_name` | Output file name (extension added from `format`). Blank = folder name | `launch_v2` |\n",
        "| `enabled` | `yes`/`no`. `no` skips the row | `yes` |\n",
        "| `overwrite` | `yes` re-renders even if the output already exists. Default `no` (lets you resume) | `no` |\n",
        "| `fps` | `1–240` or rational like `30000/1001`. Blank = composition's own fps (else 30) | `30` |\n",
        "| `quality` | `draft`, `looks` (default), `delivery`, `standard`, `high` | `looks` |\n",
        "| `resolution` | `landscape`, `portrait`, `square`, `landscape-4k`, `portrait-4k`, `square-4k`, `1080p`, `4k`… Must match the composition's aspect ratio | `landscape` |\n",
        "| `format` | `mp4`, `webm`, `mov`, `gif` | `mp4` |\n",
        "| `gpu` | `yes`/`no` — GPU (NVENC) video encoding | `yes` |\n",
        "| `browser_gpu` | `yes`/`no` — hardware Chrome/WebGL capture | `yes` |\n",
        "| `workers` | `auto` or a number of parallel Chrome workers (~256 MB RAM each) | `auto` |\n",
        "| `crf` | Encoder quality override (mp4/webm). Can't combine with `video_bitrate` | `18` |\n",
        "| `video_bitrate` | e.g. `10M`. Can't combine with `crf` | `10M` |\n",
        "| `extra_args` | Any other Hyperframes flags, passed through as-is | `--browser-timeout 120` |\n",
        "| `var_<name>` | **Any number** of columns starting with `var_`. Passed to the composition as variable `<name>` | `var_title` |\n",
        "\n",
        "`var_*` values: `true`/`false`, numbers and JSON (`[...]`, `{...}`) are typed automatically; everything else is a string. Blank = not passed. Your HTML reads them with `window.__hyperframes.getVariables()` and should declare defaults with `data-composition-variables`.\n",
        "\n",
        "## Run order\n",
        "Run the **setup cells (1–5) once per session**. After that, cells 6–9 as often as you like. If the runtime resets, run the setup cells again."

        "def to_bool(v, default=False):\n",
        "    s = str(v).strip().lower()\n",

        "    if s in (\"1\", \"true\", \"yes\", \"y\", \"on\"):    return True\n",
        "    if s in (\"0\", \"false\", \"no\", \"n\", \"off\"):   return False\n",
        "    raise ValueError(f\"expected yes/no, got {v!r}\")\n",

        "\n",
        "def parse_var(v):\n",
        "    s = v.strip()\n",
        "    low = s.lower()\n",
        "    try:\n",
        "        if low in (\"true\", \"false\") or re.fullmatch(r\"-?\\d+(\\.\\d+)?\", s) or (s and s[0] in \"[{\"):\n",
        "            return json.loads(low if low in (\"true\", \"false\") else s)\n",
        "    except Exception:\n",
        "        pass\n",
        "    return v\n",

        "\n",

        "        try:    return to_bool(r.get(key, \"\"), DEFAULTS[key])\n",
        "        except ValueError as e: errs.append(f\"{key}: {e}\"); return DEFAULTS[key]\n",
        "\n",
        "    def val(key):\n",
        "        v = r.get(key, \"\")\n",
        "        return v if v != \"\" else str(DEFAULTS[key])\n",
        "\n",
        "    job[\"gpu\"], job[\"browser_gpu\"], job[\"overwrite\"] = flag(\"gpu\"), flag(\"browser_gpu\"), flag(\"overwrite\")\n",

        "\n",
        "    # --- encoding options\n",
        "    fmt = val(\"format\").lower()\n",
        "    if fmt not in FORMATS: errs.append(f\"format '{fmt}' not in {sorted(FORMATS)}\")\n",
        "    quality = val(\"quality\").lower()\n",

        "    res = val(\"resolution\").lower()\n",
        "    if res and res not in RESOLUTIONS: errs.append(f\"resolution '{res}' not in {sorted(RESOLUTIONS)}\")\n",
        "    workers = val(\"workers\").lower()\n",
        "    if workers != \"auto\" and not (workers.isdigit() and int(workers) > 0): errs.append(\"workers must be 'auto' or a positive number\")\n",
        "    crf, bitrate = val(\"crf\"), val(\"video_bitrate\")\n",

        "               log_name=f\"{stem}.render.log.txt\",\n",

        "        jobs.append(resolve_job(i + 2, r, root))   # +2 = line number in the file (header is line 1)\n",
        "    return jobs\n",
